# 🚀 Udyaman ERP - React UI

Complete React authentication system integrated with Spring Boot RBAC backend.

## ✨ Features

✅ JWT Authentication | ✅ Role-Based Access Control | ✅ Protected Routes | ✅ Material-UI Design

## 🎯 Quick Start

```bash
# 1. Start backend
cd /Users/srinivasranjan/udyaman
./mvnw spring-boot:run

# 2. Install React dependencies
cd /Users/srinivasranjan/udyaman-react-ui
npm install

# 3. Start development server
npm run dev
```

**Access**: http://localhost:5173 | **Login**: admin / password
